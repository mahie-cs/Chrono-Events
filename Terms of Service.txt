2. WHAT THE APP DOES
--------------------
The App shows exams, assignment deadlines and events sorted into
Upcoming, Ongoing and Past. It gets this information from a public file
(events.json) hosted on GitHub. It can also:

  - save the last data it downloaded so it works offline;
  - check that file in the background about every 15 minutes and send you
    notifications about new or changed entries;
  - check the project's GitHub Releases page for new versions of the App,
    and download and install them if you choose to.
